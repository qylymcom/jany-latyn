# jany-latyn

[Kyrgyzça (Jany-Latyn)](README.ky-jany.md) · [Кыргызча (Кириллица)](README.ky.md) · [Русский](README.ru.md) · [English](../README.md) · [Türkçe](README.tr.md)

---

**Jany-Latyn** (новая латиница) — современная практическая расширенная латиница для кыргызского языка (Кыргызча).

Проект создан на основе естественных привычек транслитерации носителей языка, сочетая их с фонематической точностью и цифровой эффективностью:
**ж→j, ч→ç, ш→ş, х→h, долгие гласные пишутся сдвоенно (тоок → took, даамдуу → daamduu)**.

Для всех букв сформированы строгие и ясные правила:
- **ө** передается латинской буквой **ö / Ö** (U+00F6 / U+00D6).
- **ү** передается латинской буквой **ü / Ü** (U+00FC / U+00DC).
- **ң** передается буквой **ŋ / Ŋ** (U+014B / U+014A, eng).
- **ч** передается буквой **ç / Ç** (U+00E7 / U+00C7), **ш** передается буквой **ş / Ş** (U+015F / U+015E).
- **ы** передается как **y**, а **й** как **í / Í** (U+00ED / U+00CD).
- Знаки **ъ / ь** поглощаются глайдом `í` (*obíekt*, *semía*) или отбрасываются на конце слова (*iíul*), делая слова 100% буквенными (`\p{L}+`).

Пример:
> Ак мөңгүлүү аска, зоолор, талаалар →
> **Ak möŋgülüü aska, zoolor, talaalar**

### Ключевые правила

1. **Фонематические долгие гласные:** Пишутся сдвоенно, как и в кириллице (`аа → aa`, `ээ → ee`, `оо → oo`, `уу → uu`, `өө → öö`, `үү → üü`). Не требуют сложных надстрочных знаков и не ломают веб-поиск.
2. **Универсальный глайд `í`:** Кириллический `й` во всех позициях пишется как `í` (*aí*, *toí*, *tyíyn*, *biíik*, *kiíim*), сохраняя морфемные основы и устраняя эффект штрих-кода `iii`.
3. **Седили для шипящих и поглощение знаков:** Одиночные буквы `ç` и `ş` устраняют коллизии на стыке морфем (*başçy*, *kesçi* vs *ishak*). Знаки `ъ / ь` поглощаются глайдом `í` (*obíekt*, *semía*) или опускаются (*iíul*), исключая внутрисловные апострофы.
4. **Отсутствие `q` и `ğ`:** Твердые и мягкие аллофоны [к/къ] и [г/гъ] однозначно определяются законом сингармонизма и гласным контекстом.
5. **ASCII Fallback (резервный режим):** Для набора на обычных клавиатурах без специальных символов:
   - `ö → o`, `ü → u`, `í → i`, `ŋ → n`, `ç → ch`, `ş → sh`.
   - Пример: `Ak möŋgülüü aska` → `Ak monguluu aska`.

## Быстрый старт и CLI

Библиотека ядра транслитерации не содержит **никаких внешних зависимостей** в рантайме.

```sh
# Клонирование и сборка
git clone https://github.com/qylymcom/jany-latyn.git
cd jany-latyn
npm install && npm run build

# Конвертация через stdin или аргументы
echo "Алгалай бер, кыргыз эл" | node packages/engine/dist/src/cli.js
# Результат: Algalaí ber, kyrgyz el

echo "Ак мөңгүлүү аска" | node packages/engine/dist/src/cli.js
# Результат: Ak möŋgülüü aska

# Конвертация в ASCII fallback
echo "Ак мөңгүлүү аска" | node packages/engine/dist/src/cli.js --to fallback
# Результат: Ak monguluu aska

# Обратная транслитерация в кириллицу
echo "Ak möŋgülüü aska" | node packages/engine/dist/src/cli.js --to cyrillic
# Результат: Ак мөңгүлүү аска
```

## Веб-песочница (Playground)

Интерактивное веб-приложение на Svelte 5 и daisyUI:

```sh
npm run dev
```

Откройте `http://localhost:5173` в браузере:
- **По умолчанию в Jany-Latyn:** Сайт открывается на новой латинице, демонстрируя естественность и легкость чтения.
- **Мгновенная транслитерация:** Набирайте текст на кириллице слева и читайте латиницу справа; ASCII fallback — на отдельной вкладке.
- **Переключатель вариантов:** jany-latyn, по образцу CTA, диграфы и гибрид ө в один клик, либо настройка каждой буквы (включая альтернативы глайда `ĭ`/`ĩ` и `ñ`). Список сравнения подсвечивает слова, которые меняет каждый вариант.
- **Виртуальная клавиатура:** Слой Alt и строка быстрого ввода следуют выбранным настройкам, так что можно набрать любую букву активного варианта (см. [docs/keyboard.md](keyboard.md)).
- **Светлая и тёмная темы:** По умолчанию следует системной настройке; переключатель в меню.
- **Шрифтовая проверка:** Тестируйте отображение глифов в десятках системных и веб-шрифтов.
- **Мультиязычный интерфейс:** Переключение между **Kyrgyzça** (кыргызский, Jany-Latyn), **Кыргызча** (кыргызский, кириллица), **Русский**, **English** и **Türkçe**.

## Настройка клавиатуры (macOS и Linux)

Ввод символов `ö`, `ü`, `í`, `ŋ`, `ç`, `ş` через AltGr / Option:
- **Option / AltGr + `o`** → `ö`  (с Shift → `Ö`)
- **Option / AltGr + `u`** → `ü`  (с Shift → `Ü`)
- **Option / AltGr + `i`** → `í`  (с Shift → `Í`)
- **Option / AltGr + `n`** → `ŋ`  (с Shift → `Ŋ`)
- **Option / AltGr + `c`** → `ç`  (с Shift → `Ç`)
- **Option / AltGr + `s`** → `ş`  (с Shift → `Ş`)

### Установка в macOS
1. Скопируйте раскладку в пользовательскую папку:
   ```sh
   cp packages/engine/keymaps/jany-latyn.keylayout ~/Library/Keyboard\ Layouts/
   ```
2. Выйдите из системы и войдите снова (или перезагрузите Mac).
3. В **Системных настройках** → **Клавиатура** → **Источники ввода** нажмите **Изменить...** → **+** и добавьте **"jany-latyn"**.
4. В раскладке полностью сопоставлены все скан-коды ANSI (цифровой блок numpad, стрелки навигации, горячие клавиши терминала `Ctrl+C`, `Ctrl+D`), что полностью исключает сбои ввода.

### Установка в Linux (XKB)
```sh
mkdir -p ~/.config/xkb/symbols
cp packages/engine/keymaps/jany.xkb ~/.config/xkb/symbols/jany
setxkbmap -I$HOME/.config/xkb -layout jany -print | xkbcomp -I$HOME/.config/xkb - $DISPLAY
```

Подробнее о настройках и Wayland: [docs/keyboard.md](keyboard.md).
