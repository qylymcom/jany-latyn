# jany-latyn

[Kyrgyzça (Jany-Latyn)](README.ky-jany.md) · [Кыргызча (Кириллица)](README.ky.md) · [Русский](README.ru.md) · [English](../README.md) · [Türkçe](README.tr.md)

---

**Jany-Latyn** (жаңы латын) — кыргыз тили үчүн заманбап, практикалык кеңейтилген латын жазуусу.

Бул долбоор кыргыз тилинде сүйлөгөндөрдүн табигый жазуу адаттарына жана фонетикалык тактыкка негизделген:
**ж→j, ч→ç, ш→ş, х→h, созулма үндүүлөр кош жазылат (тоок → took, даамдуу → daamduu)**.

Бардык тамгалар үчүн так жана ырааттуу эрежелер түзүлгөн:
- **ө** тамгасы латынча **ö / Ö** (U+00F6 / U+00D6) менен берилет.
- **ү** тамгасы латынча **ü / Ü** (U+00FC / U+00DC) менен берилет.
- **ң** тамгасы **ŋ / Ŋ** (U+014B / U+014A, eng) менен жазылат.
- **ч** тамгасы **ç / Ç** (U+00E7 / U+00C7), **ш** тамгасы **ş / Ş** (U+015F / U+015E).
- **ы** тамгасы **y**, ал эми **й** тамгасы **í / Í** (U+00ED / U+00CD) болуп белгиленет.
- Орусча белгилер **ъ / ь** `í` үндүүсүнө сиңирилет же түшүрүлөт (*obíekt*, *semía*, *iíul*), натыйжада сөздөр 100% тамгалардан турат (`\p{L}+`).

Мисал:
> Ак мөңгүлүү аска, зоолор, талаалар →
> **Ak möŋgülüü aska, zoolor, talaalar**

### Негизги эрежелер

1. **Созулма үндүүлөр:** Кириллицадагыдай эле кош жазылат (`аа → aa`, `ээ → ee`, `оо → oo`, `уу → uu`, `өө → öö`, `үү → üü`). Эч кандай кошумча татаал диакритикалык белгилер талап кылынбайт.
2. **Бирдиктүү `í` тыбышы:** Кириллицадагы `й` бардык позицияларда `í` болуп жазылат (*aí*, *toí*, *tyíyn*, *biíik*, *kiíim*). Бул сөз уңгуларын бузбай сактап, `iii` штрих-код сыяктуу бүдөмүктүктү жок кылат.
3. **Седелкалуу тишчилдер жана белгилерди сиңирүү:** Бирдиктүү `ç` жана `ş` тамгалары уңгу менен мүчөнүн кагылышын алдын алат (*başçy*, *kesçi* vs *ishak*). Орусча `ъ / ь` белгилери `í` үндүүсү менен сиңирилет же түшүрүлөт (*obíekt*, *semía*, *iíul*), натыйжада сөздөр 100% тамгалардан турат (`\p{L}+`).
4. **`q` жана `ğ` колдонулбайт:** Жумшак жана жоон [к/къ] жана [г/гъ] тыбыштары үндүүлөрдүн таасиринен улам сөздүн мазмунунан табигый түрдө аныкталат.
5. **ASCII резервдик режими:** Атайын тамгалары жок стандарттуу клавиатураларда жазуу үчүн:
   - `ö → o`, `ü → u`, `í → i`, `ŋ → n`, `ç → ch`, `ş → sh`.
   - Мисалы: `Ak möŋgülüü aska` → `Ak monguluu aska`.

## Ыкчам баштоо жана буйрук сабы (CLI)

Негизги транслитерация системасы эч кандай тышкы көз карандылыктарга муктаж эмес (нөл көз карандылык).

```sh
# Репозиторийди көчүрүп алуу жана куруу
git clone https://github.com/qylymcom/jany-latyn.git
cd jany-latyn
npm install && npm run build

# Буйрук сабы аркылуу текстти айландыруу
echo "Алгалай бер, кыргыз эл" | node packages/engine/dist/src/cli.js
# Жыйынтык: Algalaí ber, kyrgyz el

echo "Ак мөңгүлүү аска" | node packages/engine/dist/src/cli.js
# Жыйынтык: Ak möŋgülüü aska

# ASCII резервдик форматына айландыруу
echo "Ак мөңгүлүү аска" | node packages/engine/dist/src/cli.js --to fallback
# Жыйынтык: Ak monguluu aska

# Кайра кириллицага айландыруу
echo "Ak möŋgülüü aska" | node packages/engine/dist/src/cli.js --to cyrillic
# Жыйынтык: Ак мөңгүлүү аска
```

## Веб оюн талаасы (Playground)

Svelte 5 жана daisyUI менен жасалган интерактивдүү веб-тиркеме:

```sh
npm run dev
```

Браузерде `http://localhost:5173` дарегине кирип, жазууну сынап көрсөңүз болот:
- **Jany-Latyn форматы демейки абалда:** Веб-сайттын өзү Jany-Latyn жазуусунда ачылып, окууга жеңил экенин дароо көрсөтөт.
- **Түз транслитерация:** Сол жакта кириллица менен териңиз, оң жакта латын жазуусун окуңуз; ASCII fallback өзүнчө өтмөктө.
- **Варианттарды которуу:** jany-latyn, CTA, диграфтар жана аралаш ө бир басуу менен, же ар бир тамганы өзүңүз тандаңыз (`ĭ`/`ĩ` жана `ñ` варианттары менен кошо). Салыштыруу тизмеси ар бир вариант өзгөрткөн сөздөрдү белгилейт.
- **Виртуалдык клавиатура:** Alt катмары жана тез киргизүү катары тандалган параметрлерге ылайыкташат, ошондуктан учурдагы варианттын ар бир тамгасын терүүгө болот ([docs/keyboard.md](keyboard.md)).
- **Жарык жана караңгы темалар:** Демейки боюнча тутумдун жөндөөсүнө ылайык; которгуч менюда.
- **Ариптерди текшерүү:** Тутумдук жана заманбап веб-ариптердин колдоосун байкаңыз.
- **Көп тилдүү интерфейс:** Кыргызча (Jany-Latyn), Кыргызча (Кириллица), Орусча, Англисче жана Түркчө тандоо мүмкүнчүлүгү.

## Клавиатура орнотуу (macOS жана Linux)

`ö`, `ü`, `í`, `ŋ`, `ç`, `ş` тамгаларын Option / AltGr аркылуу оңой терүү:
- **Option / AltGr + `o`** → `ö`  (Shift менен → `Ö`)
- **Option / AltGr + `u`** → `ü`  (Shift менен → `Ü`)
- **Option / AltGr + `i`** → `í`  (Shift менен → `Í`)
- **Option / AltGr + `n`** → `ŋ`  (Shift менен → `Ŋ`)
- **Option / AltGr + `c`** → `ç`  (Shift менен → `Ç`)
- **Option / AltGr + `s`** → `ş`  (Shift менен → `Ş`)

### macOS боюнча орнотуу
1. Файлды колдонуучунун клавиатура каталогуна көчүрүңүз:
   ```sh
   cp packages/engine/keymaps/jany-latyn.keylayout ~/Library/Keyboard\ Layouts/
   ```
2. Тутумдан чыгып кайра кириңиз (же компьютерди өчүрүп күйгүзүңүз).
3. **System Settings** → **Keyboard** → **Input Sources** → **Edit...** басып, **+** баскычы аркылуу **"jany-latyn"** клавиатурасын кошуңуз.
4. Бул жайылмада сандык клавиатура (numpad), багыттоо жебелери жана терминалдык кыска жолдор (`Ctrl+C`, `Ctrl+D`) толук иштеп, ката кетирбейт.

### Linux (XKB) боюнча орнотуу
```sh
mkdir -p ~/.config/xkb/symbols
cp packages/engine/keymaps/jany.xkb ~/.config/xkb/symbols/jany
setxkbmap -I$HOME/.config/xkb -layout jany -print | xkbcomp -I$HOME/.config/xkb - $DISPLAY
```

Толук нускама жана Wayland жөндөөлөрү: [docs/keyboard.md](keyboard.md).

```
├── packages/engine/src/
│   ├── alphabet.ts     # Негизги тамга карталары жана ASCII резерв таблицалары

│   └── cli.ts          # Консольдук программа
├── apps/web/                 # Svelte 5 + SvelteKit веб-тиркемеси
│   └── src/lib/i18n/   # Кардар тараптагы динамикалык котормолор
├── packages/engine/keymaps/  # macOS жана Linux клавиатура жайылмалары
├── packages/engine/charts/   # Генерацияланган SVG алиппе диаграммасы (alphabet.svg)
├── packages/engine/test/     # Node test runner тесттер топтому (100% ийгиликтүү)
├── docs/SPEC.md              # Расмий орфографиялык спецификация
```

Бул жазуунун терең лингвистикалык жана санариптик негиздемеси тууралуу толук маалыматты [Whitepaper (WHITEPAPER.md)](WHITEPAPER.md) документинен окуңуз.
